# Security notes

This is a public-safe snapshot.

## Removed from the private system

- real phone numbers
- real bot handles
- deployment names and URLs
- credentials
- private profile files
- private memories
- logs
- customer/prospect data

## Snapshot rules

- Tests use synthetic data.
- Any future demo data must be fake.
- Do not add `.env`, logs, database dumps, profile memory, or real user transcripts.
